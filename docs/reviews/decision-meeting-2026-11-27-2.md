# 결정 회의 기록 · 2026-11-27 (2) 금액 정정으로 수수료가 줄 때

> 방문 금액 정정(FR-STL-09, 11-25 (5))은 수수료 차액을 '가게 잔액 차감 · 공동 기금 입금'으로 남긴다고만 정해, 정정 금액이 원래보다 적어 수수료가 줄어드는 경우가 정해져 있지 않았다. D22를 구현하면서 담당 D가 정했고, 이 기록을 담은 PR의 리뷰 승인으로 확정한다. 이 기록이 이전 기록보다 우선한다.

| 주제 | 결정 | 이유 |
| --- | --- | --- |
| 수수료가 줄어드는 정정 | 줄어든 차액만큼 **공동 기금에서 가게로 돌려준다**. 원래 방문 금액 · 수수료 기록은 그대로 두고, 정정 기록과 차액 거래(기금 출금 · 가게 환급)를 추가로 남긴다 | 수수료는 실제 결제 금액의 4%라는 규칙을 정정 뒤에도 지킨다. 늘 때와 같은 방식(추가 기록 · 추가 거래) |
| 기금이 모자랄 때 | 공동 기금은 마이너스가 될 수 없으므로(FR-STL-06) 돌려줄 금액보다 기금이 적으면 정정을 거절한다(`insufficient_balance`). 아무것도 남기지 않는다 | 기금 마이너스 금지 규칙과 맞춘다 |
| 차액 계산 | 정정 금액으로 다시 계산한 수수료(원래 수수료율, 쿠폰 할인은 정정 금액 기준, 1원 미만 버림) − 지금까지 낸 수수료(원래 수수료 + 앞선 정정 차액) | 신고마다 정정할 수 있으므로 앞선 정정을 더해 이중으로 옮기지 않는다 |
| 그대로인 것 | 늘면 가게 → 기금(가게 잔액 마이너스 가능). 차액은 원래 방문(예약) 달 정산에 들어간다. 신고 한 건에 정정 한 번 | 11-25 (5) |
