# 결정 회의 기록 · 2026-11-23 (8) 화면 시안 검토 중 정한 것

> 화면 시안을 검토하면서 정한 것이다. 같은 자리에서 정한 '동네는 하나'는 [(7)](decision-meeting-2026-11-23-7.md)에 먼저 남겼다.
> 이 기록이 같은 날의 11-23 · (2) ~ (7) 기록을 포함한 이전 기록보다 우선한다. 다만 (2)에서 이미 닫은 질문(Q-11 손님 흐름 5명 미만 숨김, Q-18 소개 귀속, Q-21 기준 가게 취소 시 코스 표시)은 그대로 두고, 아래는 거기에 더하는 것만 적었다.

## 결정

| # | 주제 | 결정 |
| --- | --- | --- |
| 1 | 오늘의 코스 | **넣는다.** 같은 날 이어서 방문 처리된 기록(이동)에서 많이 이어진 3곳 동선(A→B→C)을 자동으로 보여주는 미리보기다. 사람이 고른 코스(11-23에 제거한 상인회 추천 코스)와 다르다 |
| 2 | 보낸 가게 이름 | **사장님은 볼 수 없다.** 예약 목록 · 방문 처리 결과 · 고객 카드 · 수수료 내역처럼 손님 한 명 단위 화면에서는 '추천으로 왔는지 여부'만 보인다. 손님 흐름 같은 집계 화면은 가게 단위로 보여주고 5명 미만은 숨긴다(11-23 (2) Q-11 그대로) |
| 3 | '다음 코스로 예약하기'가 열리는 때 | **기준 가게 예약을 신청하면 열린다**(승인을 기다리지 않음) |
| 4 | 기준 가게 예약이 거절될 때 | 취소와 같게 다음 코스 예약은 유지하고 코스에 '취소됨'으로 표시한다(11-23 (2) Q-21). **손님에게 다음 코스 예약은 그대로라고 알린다.** 소개 귀속은 11-23 (2) Q-18 규칙을 따른다 |

## 오늘의 코스 세부

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 동선 | 같은 손님이 같은 날 A → B → C 순서로 이어서 방문하고 셋 다 방문 처리된 것. 고유 손님 수로 센다 | '이동'과 같은 기준 |
| 기준 시점 | 오늘이 평일인지 주말인지 × 지금 시간대(추천 시간대 항과 같은 6구간) | 같은 요일 × 시간대로 자르면 5명을 넘는 동선이 거의 남지 않음 |
| 후보 | 고유 손님 5명 미만 동선, 지금 예약을 받지 못하는 가게(휴업 · 중단, 예약 꺼짐)가 들어간 동선은 뺀다 | 작은 묶음 숨김 기준, 추천 후보 제외 기준과 맞춤 |
| 순위 | 고유 손님 수 내림차순으로 최대 3개. **3개 코스의 첫 가게는 서로 달라야 한다.** 남는 동선이 없으면 보여주지 않는다 | '많이 간 길'이라는 뜻은 살리고, 인기 가게 한 곳이 코스를 다 차지하지 않게 |
| 카드 | 가게 3곳, 가게 사이 도보 정보(FR-MAP-08 규칙), '방문 데이터 기반' 배지, 쿠폰 참여 가게 수 | |
| 누르면 | 첫 가게를 기준 가게로 골목 지도를 연다. 코스를 한 번에 예약하는 기능은 없고, 기준 가게 예약 → 다음 코스로 예약 흐름을 따른다 | |
| 기록 | 오늘의 코스 노출 · 클릭을 따로 남긴다. 추천 노출(수락률 분모, 소개 7일 시작)로 세지 않는다 | 소개 판정은 다음 방문 추천 노출만 쓴다 |
