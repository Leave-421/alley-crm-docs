# 결정 회의 기록 · 2026-11-23 (7) 권역 하나로 확정

> 권역(동네)을 몇 개 둘지와 권역 탐색 메뉴를 정한 결과다.
> 이 기록이 같은 날의 11-23 · (2) ~ (6) 기록을 포함한 이전 기록보다 우선한다.

| 주제 | 결정 |
| --- | --- |
| 권역 수 | **시연과 v1 모두 한 권역(대학가 골목)으로 확정한다.** 11-23의 '여러 권역을 둘 수 있음'을 뺀다 |
| 권역 탐색 메뉴 | **없앤다.** 권역 선택, 지역명 검색, 가게 이름 검색을 모두 두지 않는다(FR-MAP-03 제외). 참여 가게 15곳이 지도에 모두 보이고 업종 필터(FR-MAP-04)가 있어 가게를 찾을 수 있다 |
| 확장 가능성 | 기능으로 만들지 않고, 발표에서 구조(가게 · 상인회 계정 · 통계가 권역 단위로 묶임)로 설명한다 |

## 바뀌지 않는 것

- 데이터의 권역 단위 구조(`06-data.md` REGION)는 그대로 둔다. 확장 설명의 근거다.
- '권역 전체 방문 비중'처럼 권역을 기준으로 쓰는 계산은 그대로다. 권역이 하나일 뿐이다.
