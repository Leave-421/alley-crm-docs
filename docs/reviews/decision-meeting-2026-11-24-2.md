# 결정 회의 기록 · 2026-11-24 (2) 소개 기준을 코스 제안으로 바꿈

> 팀 구두 상의 결과다. 정책 문장은 [`05-policy.md`](../05-policy.md) 「소개 수수료와 정산」 · 「다음 방문 추천」을 따른다.
> 이 기록이 11-24를 포함한 이전 기록보다 우선한다. 11-24의 월 정산 확정 · 방문 흐름 표현 결정은 그대로 둔다.

| 주제 | 결정 | 바뀐 것 |
| --- | --- | --- |
| 소개 예약 | 기준 가게 예약 신청 뒤 **'다음 코스로 예약하기'로, 기준 가게 예약일 당일이 끝나기 전까지** 신청한 추천 가게 예약만 소개 후보다. 판단은 신청 시각, 운영 시간대 기준 | 첫 추천 노출부터 7일 규칙을 없앤다. 지도 자동 노출 · 일반 예약 · 쿠폰 다운로드 · 적용은 소개를 만들지 않는다 |
| 연결 | 코스 예약에 제안 ID와 기준 예약 ID를 연결한다 | 노출 기록으로 소개를 판정하지 않는다 |
| 방문일 | 추천 가게 방문일은 기준 예약일 이후여도 된다. 같은 날 연속 방문 요건은 가게 간 이동 통계에만 쓴다 | — |
| 소개 확정 · 수수료 | 추천 가게(B) 방문 처리 때 예약 건당 한 번 확정한다. B 예약이 취소 · 거절되거나 방문 처리되지 않으면 소개가 아니다 | — (방문 처리 시점 유지) |
| 보낸 가게 | 제안을 만든 기준 예약의 가게(A). A 예약이 취소 · 거절되거나 A를 방문하지 않아도 B가 방문 처리되면 보낸 실적 · 수수료에 넣는다 | '방문 처리된 기준 가게 중 가장 최근 추천한 곳' 규칙을 없앤다 |
| 기준 예약일 변경 | 이미 신청한 코스 예약은 신청 당시 기준 예약일로 판정, 새 신청은 바뀐 날짜로 판정 | 새 규칙 |
| 코스 제안 수락률 | 분모: 예약 신청 뒤 실제로 표시된 정식 코스 제안(같은 기준 예약 · 추천 가게 조합 1건). 분자: 그중 소개가 확정된 제안. 분모 0이면 표시하지 않음 | 추천 노출 7일 중복 제거 분모를 없앤다 |
| 탐색 기록 | 지도 추천 · 오늘의 코스의 노출 · 클릭과 지도 추천 리롤은 탐색 기록으로만 남긴다 | 수락률 · 소개에 쓰지 않는다 |
| 리롤 | 이유 입력 없이 다음 순위 후보 최대 3곳을 바로 보여준다. 다른 묶음이 없으면 버튼을 숨긴다 | 버튼 숨김 추가 |
| 거절 | 추천을 거절할 때 **사유를 묻지 않는다.** 거절은 기록만 남기고 순위에 쓰지 않는다 | 거절 사유 선택 입력을 없앤다 |
