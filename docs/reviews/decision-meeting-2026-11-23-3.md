# 결정 회의 기록 · 2026-11-23 (3) 다음 방문 추천 로직

> 다음 방문 추천(FR-CRS)의 계산 방식을 정한 결과다. 계산식과 설정값 전체는 [`05-policy.md`](../05-policy.md) 「다음 방문 추천」에 적는다.
> 이 기록이 같은 날의 [`decision-meeting-2026-11-23.md`](decision-meeting-2026-11-23.md) · [`decision-meeting-2026-11-23-2.md`](decision-meeting-2026-11-23-2.md)를 포함한 이전 기록보다 우선한다.

## 점수 구조

| 주제 | 결정 | 이유 |
| --- | --- | --- |
| 기본값 → 실제 기록 전환 | **섞기.** 실제 기록과 공공데이터 기본값을 기록 양에 따라 섞는다(평활 상수 k, 설정값). 기록이 쌓일수록 실제 기록에 가까워진다 | 문턱값 방식은 문턱 근처에서 추천이 갑자기 바뀐다 |
| 기본값 점수 항 | 매력도 · 거리 · 업종 동반 입지(CLQ) · **시간대(요일 포함)** · 손님층(성별·연령대를 알 때). 시간대 항은 기준 시각의 요일·시간대를 보고(11-20의 '시간대·요일'을 이 항 하나로 묶음), **팀 가정으로 밝힌다** | 시간대는 '업종마다 시간 패턴이 다르다'는 근거는 있지만, 이동으로 잇는 것은 가정이다 |
| 인기 보정 | 순위는 **기대 대비 비율**로 매긴다: 같이 간 비율 ÷ B의 권역 전체 방문 비중. 같이 간 비율 계산식(11-23 (2) Q-22)은 그대로 둔다 | 같이 간 비율을 그대로 쓰면 손님이 많은 가게가 어느 기준 가게에서나 상위에 뜨고, 작은 가게는 추천을 거의 받지 못한다 |
| 쿠폰과 순위 | **쿠폰 참여 여부는 순위에 쓰지 않는다.** 추천된 카드에 '예약 혜택' 배지만 붙인다 | 우대하면 혜택을 낸 가게가 추천을 사는 구조가 된다 |
| 성별·연령대 보조 | 같은 성별·연령대 손님끼리의 비율을 따로 구해 **일정 비율로 섞는다**(설정값). 정보가 없거나 그 집단 표본이 작으면 전체 비율만 쓴다 | |
| 작은 표본 | 기준 가게 A에서 B로 같은 날 이어 방문한 고유 손님이 **5명 미만**인 쌍은 실제 기록을 쓰지 않고 기본값만 쓴다. 성별·연령대 집단 비율에도 같은 기준을 쓴다 | 손님이 적은 가게는 기대 대비 비율이 크게 튄다. '5명 미만' 숨김 규칙과 기준을 맞춘다 |
| 설정값 기본값 | 기본값 가중치: 매력도 · 거리 · CLQ 각 0.25, 시간대 · 손님층 각 0.125. 평활 상수 k = 10. 같은 집단 비율 섞는 비율 30%. **모두 팀이 정한 값으로 밝힌다** | 가중치는 공공데이터로 추정할 수 없다(연구 자료 결론). 근거가 강한 항에 무게를 둔다 |

## 후보 · 시점

| 주제 | 결정 |
| --- | --- |
| 후보에서 빼는 가게 | 기준 가게 자신, **예약을 받지 못하는 가게**(영업 상태 휴업·중단, 예약 가능 여부 꺼짐), **손님이 이미 같은 날 예약한 가게**(회원·비회원 식별이 될 때). 같은 업종과 빈 슬롯이 없는 가게는 빼지 않는다 |
| 시간대 항의 기준 시각 | 기준 가게를 예약했으면 **그 예약 시각**, 아니면 현재 시각 |

## 화면 표시

| 주제 | 결정 | 이유 |
| --- | --- | --- |
| 배지 | **'방문 데이터 기반'**: A→B 고유 손님이 5명 이상이고, A 방문 고유 손님이 k명 이상(점수에서 실제 기록 비중이 절반 이상)일 때. 그 밖에는 '지역 인기 가게' | 기본값 비중이 더 큰 추천을 방문 데이터라고 부르지 않는다 |
| 제안 이유 문구 | **숫자를 보여주지 않는다.** 근거 종류별 문구로 안내한다 | 손님은 흐름·매출 데이터를 볼 수 없다(FR-CUS-05) |
| 리롤 | **다음 순위 3곳**을 보여주고, 끝까지 보면 처음으로 돌아간다 | 동작을 설명하기 쉽고 재현된다 |
| 거절 · 리롤 반영 | **기록만 남기고 순위에는 반영하지 않는다** | |

## 보류 유지

- 상인회가 화면에서 추천 가중치를 조절하는 기능 (11-20 결정 보드 2:2 보류). 가중치는 코드 밖 설정값으로만 둔다.
