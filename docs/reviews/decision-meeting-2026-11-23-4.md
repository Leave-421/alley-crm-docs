# 결정 회의 기록 · 2026-11-23 (4) 예약 시각 기준 정리

> `05-policy.md`를 쓰면서 나온, 시각 기준이 비어 있던 세 곳을 정한 결과다.
> 이 기록이 같은 날의 11-23 · 11-23 (2) · 11-23 (3) 기록을 포함한 이전 기록보다 우선한다.

| 주제 | 결정 | 이유 |
| --- | --- | --- |
| '하루 전까지 100% 환불'의 '하루 전' | **예약 시각 24시간 전**까지. 가게 취소 마감도 이보다 이르게 잡을 수 없다 | 쿠폰 기한(7×24시간)과 같은 방식으로 시각을 센다 |
| 소개 7일 · 쿠폰 7일 기한의 '예약한 시점' | **손님이 예약을 신청한 시각**으로 판단한다. 신청 뒤 사장님이 거절하면 쿠폰은 기존 규칙대로 적용 취소된다 | 사장님 승인이 늦어도 손님이 손해 보지 않게 한다 |
| 사장님이 승인도 거절도 하지 않은 '신청' 예약 | **예약 시각까지 승인이 없으면 자동으로 거절**한다. '가게 거절'과 같이 처리해, 취소 사유는 '가게 거절', 예약금 100% 환불, 쿠폰 적용 취소 | 가게가 응답하지 않은 것이므로 손님이 예약금을 잃지 않게 한다. '예약일 다음 날 자동 취소(환불 없음)'는 확정된 예약에만 적용된다 |
| 확정 예약을 변경해 다시 '신청'이 됐는데 승인이 없는 경우 | 원래 예약 시각과 바뀐 시각 중 **이른 쪽까지 승인이 없으면 변경만 자동 거절**하고 원래 확정 예약을 유지한다 | 사장님이 변경을 거절한 것과 같은 결과로 둔다 |
