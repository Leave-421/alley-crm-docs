# 결정 회의 기록 · 2026-11-27 예약 변경의 예약금 · 기한

> 예약 변경(FR-RSV-07)은 날짜 · 인원을 바꾸고 사장님이 다시 승인하는데, 인원이 바뀔 때 예약금(인원당 금액 × 인원)과 변경을 신청할 수 있는 기한이 정해져 있지 않았다. 담당 D가 제안하고 이 기록을 담은 PR의 리뷰 승인으로 확정한다. 이 기록이 이전 기록보다 우선한다.

| 주제 | 결정 | 이유 |
| --- | --- | --- |
| 인원 변경과 예약금 | 사장님이 변경을 **승인할 때** 차액을 정산한다. 늘면 차액을 더 내고, 줄면 차액을 돌려받는다(회원은 가상 잔액, 비회원은 전화번호 기록). 거절 · 자동 거절이면 돈은 그대로다 | 승인되지 않은 변경으로 돈이 오가지 않게 한다 |
| 잔액 확인 | 인원이 늘어 회원이 더 내야 하면 **변경 신청 때** 잔액을 확인해, 모자라면 신청을 거절한다(`insufficient_balance`, 충전 안내). 승인 때 다시 모자라면 승인을 거절한다 | 사장님이 승인하려는 순간에 실패하는 일을 줄인다 |
| 변경 기한 | **가게 취소 마감 전까지**만 변경을 신청할 수 있다(취소와 같은 기한, FR-RSV-06) | 마감 뒤 취소 대신 변경으로 마감을 피해 가지 않게 한다 |
| 그대로인 것 | 변경하면 '신청'이 되고 원래 값은 그대로 둔 채 바꿀 값이 대기한다. 거절 · 원래 시각과 바뀐 시각 중 이른 쪽까지 승인이 없으면 원래 예약으로 '확정' 유지. 같은 예약 ID라 적용된 쿠폰은 그대로(05-policy) | |
