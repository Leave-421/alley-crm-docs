# 결정 기록 · 2026-11-25 (3) 예약 화면 쿠폰 직접 선택

> 11-25 추가 결정(중단 뒤 새 행사, 30일 제한은 행사 단위)으로 회원이 같은 가게 쿠폰을 두 장 가질 수 있게 됐다. 그런데 FR-CPN-06은 "유효 쿠폰을 자동으로 고른다"고만 해서 두 장 중 어느 것을 고를지 정해지지 않았다(Q-28). 자동 선택을 없애고 회원이 직접 고르게 한다. 담당 E(쿠폰 적용 E13)가 제안하고, 이 기록을 담은 PR의 리뷰 승인으로 확정한다. 이 기록이 이전 기록보다 우선한다.

| 주제 | 결정 | 이유 |
| --- | --- | --- |
| 쿠폰 고르기 | 예약 화면은 쿠폰을 **자동으로 고르지 않는다.** 회원이 그 가게의 사용 가능한 쿠폰 목록에서 **직접 하나** 고른다 | 쿠폰이 두 장일 때 자동 선택 기준(기한 · 할인 크기 · 받은 순서)을 정할 필요가 없다. 정률 할인은 방문 금액을 알아야 크기를 비교할 수 있어 예약 시점에 공정하게 비교할 수 없다 |
| 기본값 | **'적용 안 함'.** 쿠폰이 한 장뿐이어도 미리 고르지 않는다 | 규칙이 하나로 단순하고, 회원이 모르는 사이에 쿠폰이 쓰이는 일이 없다 |
| 상태 | 화면에서 고르거나 고르지 않는 것은 쿠폰 상태를 바꾸지 않는다. 신청할 때 고른 쿠폰만 '예약에 적용됨'이 된다. 05-policy 상태 표의 '예약에 적용됨 → 손님이 예약 화면에서 적용 해제 → 다운로드됨' 행은 자동 선택을 전제로 한 것이라 뺀다 | 신청 뒤에 예약에서 쿠폰을 떼어 내는 화면(G-04 · G-05)은 원래 없다 |
| 그대로인 것 | 예약 한 건에 쿠폰 하나, 비회원은 쿠폰 없이 진행, 기한은 신청 시각으로 판단, 고르지 않은 쿠폰은 기한 안에서 다른 예약에 사용 가능 | |
