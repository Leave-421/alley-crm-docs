## 읽는 법

- ID: `FR-<영역>-<번호>`, `NFR-<번호>`. 번호는 두 자리이고, 한 번 붙인 ID는 지우지 않고 「제외」로 바꾼다.
- 우선순위: 필수 / 여유 / 제외. **표의 값은 모두 초안**이다(Q-01).
  - 필수: 시연(사장님·상인회 중심) 흐름이 끊기는 기능, CRM 뼈대(고객 카드·등급·세그먼트)
  - 여유: 있으면 좋지만 빠져도 시연 흐름이 이어지는 기능
- 근거 열 약어: 「정리·절 이름」 = v1 결정 정리의 절, `11-18 A1` · `11-19 D4` · `11-20 #9` · `11-23` · `11-23(2)` · `11-23(3)` · `11-23(4)` · `11-23(5)` · `11-23(6)` = 결정 회의 기록의 안건. `11-23(2)`는 같은 날 두 번째 기록(열린 질문 정리), `11-23(3)`은 세 번째 기록(다음 방문 추천 로직), `11-23(4)`는 네 번째 기록(예약 시각 기준 정리), `11-23(5)`는 다섯 번째 기록(데이터 연결 기준), `11-23(6)`은 여섯 번째 기록(인수 조건 작성 중 정한 것)이다.

## 용어

| 다음 코스 | 기준 가게 예약 뒤 추천 가게를 이어서 예약한 것 | 코스 예약, 내 예약 |

| 방문 처리 | 사장님이 손님이 실제로 왔다고 입력하는 것. 예약이 '방문' 상태가 된다 | 수수료 발생, 수락 확정, 방문 횟수 |
| 추천 쿠폰 | 추천 카드에 뜬 대상 가게의 혜택. 회원만 직접 다운로드 | 쿠폰, 예약 |
| 가상 잔액 | 실제 돈 대신 쓰는 포인트. 거래 내역만 남는다 | 예약금, 소개 수수료, 상인회 기금 |
| 묶음 숫자 | 손님 한 명 단위가 아닌 집계 값. 5명 미만 묶음은 '5명 미만'으로 표시한다 | 상인회 화면, 사장님 손님 흐름(FR-ANL-02) |
